# FTP Testing — Complete Guide

_Source: Empirical Cycling Podcast — Kolie Moore_

---

## What Is FTP?

FTP is the power output you can sustain at **maximal lactate steady state (MLSS)** — the highest intensity at which lactate production and clearance are still in balance. It is **not** 95% of 20-minute power and it is **not** a fixed duration (e.g., "60-minute power"). It manifests as the **inflection point** on your power-duration curve: above it, fatigue accelerates sharply; below it, fatigue accumulates much more slowly.

> FTP is physiologically defined, not mathematically derived. It is a state, not a number extracted from a formula.

---

## How to Find FTP — The Inflection Point Method

The only reliable signal is finding the threshold where fatigue rate changes:

- **Above FTP** → fatigue accumulates fast (e.g., 5–10% over FTP halves your time to exhaustion)
- **Below FTP** → fatigue accumulates slowly (5–10% under FTP can extend TTE by 50–100%+)

**Concrete example** (200 W FTP, 40-min TTE):

| Power     | % FTP | Sustainable Duration | % of FTP-TTE |
| --------- | ----- | -------------------- | ------------ |
| 170 W     | 85%   | ~100 min             | 250%         |
| 180 W     | 90%   | ~80 min              | 200%         |
| 190 W     | 95%   | ~60 min              | 150%         |
| **200 W** | **100%** | **40 min**        | **100%**     |
| 210 W     | 105%  | ~21 min              | 50%          |
| 220 W     | 110%  | ~10 min              | 25%          |

This asymmetry is the definition of FTP — find it by feel or by reading your power curve.

---

## Testing Approaches

### The Preferred Method: Open-Ended Ramp-Up Test

The most accurate and coach-recommended approach. No fixed duration — the test ends when you find your sustainable ceiling.

**Protocol:**
1. Start **~20 W below** your suspected FTP for 10–15 minutes
2. Ramp up slowly until you find the pace where "if I go a little harder, I won't last much longer — but if I hold here, I can go quite a bit further"
3. Hold that edge as long as possible
4. **Do not jump straight to your suspected FTP** — this fails ~98% of the time

**What you're looking for:** a 5–10 W band where the sensation of sustainable steady-state is clear. This isn't a 1-watt precision game — it's a felt range.

### Alternative: Fixed-Duration Test (15–30 min)

Useful when you need a concrete anchor or when athletes are prone to under-pacing an open-ended test.

- A **15–25 minute range** works well — if you blow up at 17 min or push to 22 min, it's still valid data
- Blowing up slightly is not failure — the power curve still gets updated
- **Avoid the classic 20-min test + 5% correction** for most athletes — the "95%" rule has large individual error

### ERG Mode Testing

Valid only if your goal is to read the **power curve** afterward and identify the inflection point visually. ERG mode itself defeats the primary purpose: **learning to feel your FTP**. Use it sparingly and don't treat the locked wattage as the answer in isolation.

**The "brute-force" ERG method** (mentioned as a conceptual tool, not a practical protocol):
Set ERG to 10 W below suspected FTP → hold as long as possible → rest → set to 10 W above → repeat. The inflection between the two durations reveals FTP. This is time-inefficient and not recommended for regular use.

---

## ERG Mode vs. Free-Riding

| Factor                   | ERG Mode             | Free-Riding / Open                  |
| ------------------------ | -------------------- | ------------------------------------ |
| Pacing control           | Automatic            | Requires skill (learnable)           |
| Feel development         | Bypassed             | Core benefit                         |
| Power curve data         | Clean, usable        | Clean if paced well                  |
| Risk of wrong wattage    | High — locked in     | Self-correcting if athlete is honest |
| Recommended for testing? | Rarely / cautiously  | Yes — primary method                 |

## Feeding the Power-Duration Model

FTP can be assessed without dedicated tests by keeping your **power-duration curve well-populated** across durations:

| Range           | Example efforts                                    |
| --------------- | -------------------------------------------------- |
| 10–15 sec       | Sprint (anaerobic)                                 |
| 30–60 sec       | Hard punch or VO2 effort                           |
| 3–6 min         | VO2max interval                                    |
| 10–30 min       | Threshold or FTP interval                          |
| 60–90 min       | Long tempo, over-unders, or race effort            |

When all ranges are covered, the inflection point in the model becomes reliable without a dedicated test. Regular interval work naturally fills the model — only short-duration anaerobic data tends to get sparse and may need a deliberate effort.

---

## When to Test

| Situation                          | Recommendation                                          |
| ---------------------------------- | ------------------------------------------------------- |
| New athlete / unknown baseline     | Dedicated ramp-up test first; establish a reference     |
| Early in a training block          | Test before setting interval targets                    |
| Mid-block (4–8 weeks in)           | Re-test if intervals feel systematically easy or hard   |
| After a race or long effort        | Race data may update the model — check curve first      |
| **Do not** auto-add 5 W every cycle| FTP may not have moved — test instead of assuming       |

**Standard interval**: every 4–8 weeks for most athletes. Experienced athletes with small year-over-year gains may test less frequently.

---

## Precision and Day-to-Day Variation

- FTP does **not** change by 10–20 W week to week — that variation is fatigue, glycogen, or power meter error
- Power meters have ±1–3% error. At 300 W, that's ±3–9 W — precision beyond this is not meaningful
- If interval performance drops significantly week to week, the answer is **rest and food**, not FTP recalibration
- When reading the curve, picking a point **slightly lower** than the apparent inflection is always safer than going high

---

## Heart Rate as an FTP Proxy

Heart rate at FTP varies significantly (~160–180 bpm across individuals and conditions). It is not a reliable standalone test metric, especially:
- Early in the season (plasma volume low, HR elevated)
- After caffeine, poor sleep, or high heat
- Across different training states

Heart rate is **a feedback tool**, not a primary testing signal.

---

## Common Errors in FTP Testing

| Mistake                                  | Consequence                                               |
| ---------------------------------------- | --------------------------------------------------------- |
| Jumping straight to suspected FTP        | Almost always fails; pacing collapses mid-interval        |
| Sticking to one fixed wattage long-term  | "Rut" in perceived effort; real gains go undetected       |
| Using ramp test % without individual calibration | Can significantly over- or under-estimate FTP    |
| Adjusting FTP weekly based on interval feel | Chasing fatigue, not physiology                        |
| Treating 95% × 20-min power as universal | Valid on average; high individual error at the tails      |

---

## Key Principle

FTP testing is fundamentally about finding a **physiological state**, not extracting a number from a formula. The most reliable tests train the athlete to feel the threshold — which builds a durable internal reference that outperforms any fixed protocol over time.
