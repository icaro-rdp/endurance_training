# Finding FTP by Feel: RPE Accuracy, MLSS Agreement, and The Perceptual Anchor Framework — Complete Guide
_Source: Empirical Cycling Podcast — Kolie Moore & Kyle Hanson (Watts Doc #57)_

---

## What Is Finding FTP by Feel?

In modern data-driven cycling, athletes often believe that Functional Threshold Power (FTP) or Maximal Lactate Steady State (MLSS) can only be identified through mathematical formulas (e.g., $95\%$ of 20-min power), multi-parameter Critical Power (CP) algorithms, or invasive blood lactate step tests.

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                        THE EPISTEMIC BOOMERANG IN CYCLING                              │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ 1. THE BIOLOGICAL PHENOMENON: Sustainable vs. non-sustainable work rate.               │
│ 2. THE ABSTRACT MODEL: 20-min tests, ramp tests, Critical Power formulas, MLSS assays. │
│ 3. THE FALLACY: Assuming the formula/test DEFINES the threshold.                       │
│ 4. THE CORRECTION: The brain (the master integrator) senses metabolic stability        │
│    directly via somatic and afferent respiratory feedback (RPE).                       │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

**The Core Principle:** The human brain functions as a master physiological integrator, synthesizing afferent signals from active muscle fibers, baroreceptors, chemoreceptors, and respiratory drive into a unified sensation of **Rating of Perceived Exertion (RPE)**. When properly anchored, an athlete can identify their true metabolic threshold by feel within $\pm 5\text{--}10\text{ watts}$ without relying on external testing algorithms.

## Key Physiological Mechanisms / How to Think About It

### 1. The Evidence: RPE vs. Critical Power vs. MLSS (The 2016 Landmark Study)

A definitive physiological trial compared self-selected RPE trials, 5-parameter Critical Power testing, and formal MLSS laboratory step testing in trained cyclists:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                        TESTING METHODOLOGY VS. TRUE MLSS                               │
├───────────────────────┬───────────────────────────────┬────────────────────────────────┤
│ Testing Modality      │ Mean Power Output (Watts)     │ Bland-Altman Agreement vs MLSS │
├───────────────────────┼───────────────────────────────┼────────────────────────────────┤
│ **True MLSS**         │ $233 \pm 42\text{ W}$         │ Reference Standard             │
├───────────────────────┼───────────────────────────────┼────────────────────────────────┤
│ **Self-Selected RPE** │ $233 \pm 41\text{ W}$         │ **Zero Bias; 11/13 within 10W**│
├───────────────────────┼───────────────────────────────┼────────────────────────────────┤
│ **Critical Power (CP)**│ $253 \pm 44\text{ W}$        │ **+20 W Positive Bias (Over)** │
└───────────────────────┴───────────────────────────────┴────────────────────────────────┘
```

* **Key Takeaway:** Cyclists riding blind with zero power or heart rate feedback—adjusting resistance purely by subjective perception—matched laboratory MLSS identically. 
* **The Critical Power Problem:** Mathematical CP algorithms consistently over-predicted sustainable threshold by an average of $+20\text{ watts}$, setting training targets that would cause premature failure in steady-state workouts.

### 2. The Perceptual Anchor Framework

To use RPE accurately, perception must be calibrated against real physiological boundaries rather than abstract numbers:

```
  RPE Scale (1–10)
  ┌── 1-2: Easy Recovery (Fasting spin, casual walking)
  ├── 3-4: Aerobic Base (Zone 2, VT1 / LT1, fully conversational, nose breathing)
  ├── 5-6: Tempo / Sweet Spot (Hard aerobic, sentence fragments)
  ├── 7-8: ★ THRESHOLD / FTP / MLSS ★ (Rhythmic breathing, distinct muscular burn, sustainable 35-70 min)
  ├── 9:   VO2max Severe Domain (Hyperventilation, gasping, unsustainable >5-8 min)
  └── 10:  Maximal Anaerobic Sprint (All-out neuromuscular burst, 5-30 sec)
```

* **Memory Anchoring:** In early exercise testing (e.g., Borg, 1982), researchers instructed subjects to anchor RPE against specific remembered exertion levels (lowest possible effort vs. maximal exhaustion).
* **High-Anaerobic Confounders:** Riders with large anaerobic work capacity ($W'$) can mask threshold intensity for 5–10 minutes by relying on glycolytic reserves. Anchoring requires riding long enough ($>15\text{--}20\text{ minutes}$) for anaerobic contributions to deplete and true oxidative equilibrium to emerge.

### 3. Somatic Cues: Lungs vs. Legs Dissociation

```
  EXACT THRESHOLD (FTP / MLSS)
  ├─► Pulmonary Ventilation: Stable, rhythmic, deep diaphragmatic breaths (NOT gasping)
  └─► Peripheral Muscle: Moderate to high tension, steady acidosis clearance equilibrium
  
  ABOVE THRESHOLD (Severe Domain / >MLSS)
  ├─► Pulmonary Ventilation: Ragged, hyperventilatory, conversational breakdown (Lungs limit)
  └─► Peripheral Muscle: Rapid $[H^+]$ and inorganic phosphate ($P_i$) accumulation
```

* **The Rule of Ventilation:** If your breathing becomes ragged, rapid, or out of control within the first 10 minutes, you are above FTP.
* **The Rule of Peripheral Burn:** At true FTP, you feel a distinct muscular workload that remains constant. If power is raised by just $+10\text{ watts}$, the difficulty increases disproportionately, whereas dropping $-10\text{ watts}$ feels immediately sustainable.

## Practical Application & Prescriptions

### 1. Pacing the Kolie Moore FTP Test by Feel

The empirical threshold test is designed to eliminate anaerobic overestimation while training the athlete's internal sensory gauge:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                        KOLIE MOORE FTP TEST PACING PROTOCOL                            │
├───────────────────┬───────────────────┬────────────────────────────────────────────────┤
│ Phase             │ Duration          │ Power Target & Perceptual Cue                  │
├───────────────────┼───────────────────┼────────────────────────────────────────────────┤
│ **1. Buy-In**     │ 5–10 minutes      │ Start at 90–95% of estimated FTP (RPE 6).      │
│                   │                   │ Allow aerobic systems & stroke volume to settle│
├───────────────────┼───────────────────┼────────────────────────────────────────────────┤
│ **2. Steady State**│ 15–20 minutes    │ Settle precisely on target FTP (RPE 7).        │
│                   │                   │ Maintain deep, controlled, rhythmic breathing. │
├───────────────────┼───────────────────┼────────────────────────────────────────────────┤
│ **3. Poke Ceiling**│ 10–15 minutes    │ Gradually increase power by +5 to +10 watts.   │
│                   │                   │ Assess if breathing remains steady or breaks.  │
├───────────────────┼───────────────────┼────────────────────────────────────────────────┤
│ **4. Empty Tank** │ Final 3–5 minutes │ Ride at maximal sustainable effort.            │
│                   │                   │ Conclude test upon voluntary exhaustion (TTE). │
└───────────────────┴───────────────────┴────────────────────────────────────────────────┘
```

### 2. Refining FTP During Regular Workouts

Instead of scheduling formal testing days every 4 weeks, assess FTP continuously through interval execution:
* **The $2 \times 20\text{ min}$ or $3 \times 15\text{ min}$ Calibration:**
  * If the first repetition feels like RPE 6.5–7.0 and you can finish the second repetition with steady power and stable heart rate, your FTP is set correctly.
  * If finishing rep 2 requires a maximal VO2max-style mental battle with ragged breathing, your dialed FTP is $10\text{--}15\text{ watts}$ too high.
  * If power can be increased by $+10\text{ watts}$ in the final 10 minutes without respiratory distress, adjust your modeled FTP upward.

## Common Pitfalls & Limitations

> [!WARNING]
> **The Aspirational FTP Trap:** Forcing a target wattage on screen because you "want" your FTP to be 300 watts or because an online ramp test produced that number. Pacing by ego overrides somatic feedback, causing athletes to accumulate severe metabolic fatigue in the first 10 minutes and blowing up workouts.

1. **Relying on Short Step Tests ($2\times 8\text{ min}$ or 20-min without blowout):**
   * Anaerobic riders can buffer high power for 8–20 minutes, yielding modeled FTP estimates $30\text{--}60\text{ watts}$ above their actual 45-minute MLSS.
2. **Ignoring Environmental Heat and Glycogen Depletion:**
   * High ambient heat ($>30^\circ\text{C}$) elevates core temperature, cardiovascular drift, and perceived exertion for a given wattage. Adjust target threshold down by $10\text{--}20\text{ watts}$ in hot conditions.
   * Severe glycogen depletion elevates respiratory rate at low power, creating false RPE cues. Test only when fully fueled.
3. **Using Unanchored 1–10 Scales:**
   * Thinking that RPE is purely arbitrary. RPE must be tied to physiological inflection points (LT1, LT2, VO2max).

## Summary Checklist / Decision Table

### FTP Pacing & RPE Diagnostic Matrix

| Sensation / Physiological Sign | Diagnostic Interpretation | Recommended Action |
| :--- | :--- | :--- |
| **Breathing deep, controlled; legs working steadily** | Right at true FTP (MLSS steady state) | Hold wattage steady; test TTE duration |
| **Hyperventilation / gasping in $<10$ min** | Above FTP (Severe intensity domain) | Immediately drop target power by 10–15 W |
| **Legs effortless; heart rate completely flat** | Below FTP (Tempo / Sweet Spot) | Poke the ceiling: lift power by +5–10 W |
| **RPE drifts from 7 to 9.5 over 40 minutes** | Approaching true Time-to-Exhaustion (TTE)| Normal physiological fatigue; record TTE |
| **20-min test gave 320W, but can't hold 300W for 25m** | Inflated test artifact from high $W'$ | Recalibrate FTP to ~285–290 W by feel |

### Coach & Athlete Action Checklist

* [ ] **Trust Internal Sensory Feedback:** Use the power meter to record performance, but use RPE and breathing mechanics to govern instantaneous pacing.
* [ ] **Always Start FTP Tests Conservatively:** Begin the first 5–10 minutes 10–15 watts below estimated threshold to allow oxygen kinetics to stabilize.
* [ ] **Monitor Respiratory Mechanics:** Use ventilatory stability as the hard boundary between heavy (threshold) and severe ($VO_{2\text{max}}$) domains.
* [ ] **Discard Flawed Algorithmic Multipliers:** Never multiply short durations (8-min, 20-min) by fixed percentages without validating continuous duration ($>35\text{--}45\text{ min}$).
* [ ] **Treat FTP as a Range:** Understand that daily threshold fluctuates by $\pm 5\text{--}10\text{ watts}$ based on sleep, temperature, fatigue, and fueling.
