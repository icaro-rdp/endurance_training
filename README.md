# Endurance Training Repository

This repository contains endurance training research, articles, and training plan materials.

## Contents

- `training_plan.tex` — main LaTeX source for the endurance training plan.
- `training_plan.pdf` — generated PDF version of the training plan.
- `Articles/` — curated markdown articles covering HIIT, metrics, nutrition, physiology, strength, and training topics.
- `Episodes/` — podcast episode notes and training summaries.

## Notes

- The repository is organized for easy access to evidence-based cycling and endurance training guidance.
- Use the LaTeX source in `training_plan.tex` to regenerate the PDF with your preferred LaTeX toolchain.
