# Episode Template

Use this as the default shape for a transcript converted into a project markdown note.

```md
---
title: "<Episode Title> — Q&A Guide"
category: "<canonical_category>"
topics:
  - "<Topic1>"
  - "<Topic2>"
source: "<Podcast Name> — <Hosts/Guests>"
author: "<Author/Host>"
date: "<YYYY-MM-DD>"
summary: "<1-2 sentence overview of key questions addressed in the episode.>"
key_takeaways:
  - "<Key takeaway 1>"
  - "<Key takeaway 2>"
  - "<Key takeaway 3>"
---

## What Is <Topic>?

<Concise definition and core framing.>

## How to Think About It

<Main explanations, models, or distinctions.>

## How to Apply It

<Practical guidance, prescriptions, or workflow.>

## When to Use It

<Good use cases and poor use cases, if relevant.>

## Key Metrics or Signals

<What to track, notice, or compare.>

## Pros and Cons Summary

**Pros**

- ...

**Cons**

- ...

## Decision Checklist

1. ...
2. ...
3. ...
```

Adapt the section names to the transcript, but keep the overall guide-like structure.
